03 // Projects

Things I've Built

Real systems with real architecture decisions — not just tutorials.

Trace Lens
Real-time distributed tracing system built from scratch. Visualizes live request flows across 4 microservices with a D3 force graph and waterfall span view. Uses a custom Prefix Trie for O(k) lookup and a fixed worker thread pool for off-main-thread latency aggregation.
Node.js D3.js WebSockets C++ Vercel
SwiftRoute
Real-time delivery dispatch simulator modeling a city road network as a weighted graph. Dijkstra's algorithm with a binary min-heap powers shortest-path routing; a nearest-rider dispatch strategy was benchmarked against a naive baseline across 300 simulated orders, cutting average delivery distance by 10.4%. Dockerized C++ backend on Render, live-polling Leaflet.js frontend on Vercel.
C++17 Dijkstra Docker Leaflet.js Render
LRU Cache
High-performance Least Recently Used cache in C++ achieving O(1) time for get/put. Thread-safe with std::mutex, comprehensive cache metrics, custom benchmarking utility, and clean CMake build.
C++17 std::mutex CMake Systems
SBI Nudge
Intelligent multi-agent financial personalization engine built with LangGraph and Streamlit. 3-node pipeline for behavior analysis, RAG-based context retrieval, and LLM-driven message synthesis with ChromaDB for real-time SBI compliance.
LangGraph ChromaDB Streamlit RAG
DataBrief
AI-powered web research and report generation with dual-agent architecture (search + reader). Uses Tavily API, LangChain LCEL, Groq LLaMA 3.3 70B, and a writer-critic loop to produce structured research reports from natural language prompts.
LangChain Groq LLM LCEL Tavily Streamlit
The Vault
Full-stack movie recommendation and discovery app. Content-based filtering with TF-IDF and cosine similarity, TMDB API integration for real-time metadata, FastAPI backend on Render, pickle-based model persistence for fast inference.
FastAPI TF-IDF TMDB API Streamlit Render
Portfolio v1
The original multi-page portfolio built with vanilla HTML, CSS, and JavaScript. Features GSAP animations, canvas background, welcome popup, accordion sections, and active tab highlighting. The foundation that led to this upgrade.
HTML CSS JavaScript GSAP GitHub Pages
Plan-Z
AI-powered productivity workspace running a multi-agent Gemini pipeline that breaks natural-language input into structured plans, ranks tasks by urgency, and autonomously escalates work falling behind deadline with auto-generated mitigation plans.
